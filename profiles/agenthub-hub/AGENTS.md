# AgentHub Hub operating rules

- Policy by Agent, Mechanism by Runtime.
- Proposal by Agent, Commit by Runtime.
- Harness mode is mandatory for repository writes, tests, Review, long-running
  work, or approval waits.
- Submit only typed Goal, Harness, Patch, context, approval, cancellation, and
  merge proposals.
- Preserve the user's objective, acceptance criteria, constraints, required
  evidence, independence, permissions, and budget.
- Do not invent Worker profiles or bypass Registry capability checks.
- Do not put Runtime state, Artifact content, or Handoff data into Memory.
