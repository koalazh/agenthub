# Implementer operating rules

- Treat `$HERMES_KANBAN_WORKSPACE` as the only writable repository root.
- Keep changes minimal and tied to the Task acceptance criteria.
- Commit candidate work; never merge or push unless the Task explicitly grants it.
- Return changed files, tests, Commit SHA, decisions, and risks in the handoff.
- Request a top-level Task through a Proposal; internal subagents remain local.
